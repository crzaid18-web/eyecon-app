# EYECON OPTICS — النسخة المستقلة (GitHub + Google Sheets)

البرنامج يُفتح من رابط GitHub Pages، والدخول بيوزر وباسورد تمنحه أنت، وكل البيانات تُحفظ في ملف Google Sheet تختاره.

## الملفات
- `index.html` — البرنامج.
- `config.js` — فيه رابط الخادم (تضعه مرة واحدة).
- `apps-script/Code.gs` — كود الخادم الذي يُلصق في Google Apps Script داخل ملف الشيت.

## 1) تجهيز Google Sheet (مرة واحدة)
1. أنشئ ملف Google Sheet جديداً في Drive (مثلاً «EYECON Database»).
2. من القائمة: **الإضافات (Extensions) ← Apps Script**.
3. احذف الكود الموجود والصق محتوى `Code.gs` كاملاً، ثم احفظ.
4. اضغط **نشر (Deploy) ← نشر جديد (New deployment)**، واختر النوع **تطبيق ويب (Web app)**:
   - Execute as: **Me** (أنت)
   - Who has access: **Anyone**
5. اضغط Deploy ووافق على الصلاحيات بحسابك، ثم انسخ **Web app URL** (ينتهي بـ `/exec`).

## 2) ربط البرنامج بالشيت
افتح `config.js` وضع الرابط بين علامتي الاقتباس:
```js
window.EYECON_API = 'https://script.google.com/macros/s/XXXX/exec';
```

## 3) النشر على GitHub Pages
1. أنشئ مستودعاً (Repository) جديداً، مثلاً `eyecon-app`.
2. ارفع الملفات `index.html` و `config.js`.
3. من **Settings ← Pages**: Source = `Deploy from a branch`، Branch = `main` / `(root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://اسمك.github.io/eyecon-app/`.

## 4) أول دخول
- أول من يفتح الرابط ينشئ **حساب المدير** (افتحه أنت مباشرة بعد النشر).
- من **الإعدادات ← المستخدمون والدخول ← إدارة المستخدمين** تضيف الموظفين: اسم مستخدم بالإنكليزي، كلمة مرور، وصلاحية (مدير / موظف / مشاهدة فقط). تستطيع إيقاف أي مستخدم أو تغيير كلمة مروره.

## 5) نقل البيانات الحالية
من نسخة Claude الحالية: الإعدادات ← النسخة الاحتياطية ← «تحميل نسخة احتياطية»، ثم في النسخة الجديدة: الإعدادات ← «استيراد نسخة احتياطية (JSON)».

## ملاحظات
- كل قسم يُحفظ في ورقة باسمه (patients, sales, items…): العمود A رقم السجل، B وقت التعديل، C ملخص مقروء، ومن D السجل كاملاً. لا تعدّل هذه الأوراق يدوياً.
- ورقة `_users` فيها المستخدمون، وكلمات المرور محفوظة مشفّرة.
- عند تعديل `Code.gs` لاحقاً: Deploy ← Manage deployments ← تعديل ← Version: New version (يبقى الرابط نفسه).
- الأجهزة تتزامن تلقائياً كل بضع ثوانٍ.
